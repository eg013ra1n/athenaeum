**Goal:** The public portal for Stage-II collaboration — a React SPA (directory, project page, new-project form, coordinator admin, email-OTP session sign-in) served by the same Axum binary at `projects.artfrom.space`/`test-hub.artfrom.space`, plus the hub-side hardening gates the slice-1 final review required before any public exposure.

**Architecture:** Extends `athenaeum-hub` (repo `/Volumes/BigMac/Users/astrobureau/Documents/Projects/athenaeum-hub`). Browser auth = a new `portal_sessions` table + HttpOnly cookie, redeemed through the SAME OTP machinery as device sign-in (shared helpers extracted from `routes/auth.rs`); a new `require_account` middleware accepts EITHER a device bearer token OR a session cookie and feeds the existing collab handlers (they only use `account_id`). The SPA lives in `portal/` (Vite + React + TS + Tailwind v4), is embedded into the release binary via `rust-embed` (debug builds read `portal/dist` from disk at runtime — rust-embed's default), and Axum serves it with an SPA fallback that injects OpenGraph tags for `/p/{slug}` (Discord embeds, spec §6). Single artifact → the existing astronet deploy playbook needs zero changes.

**Tech Stack:** Rust 1.96.1, axum 0.8 (+ axum-extra 0.10 `cookie`), sqlx 0.8, rust-embed 8; Vite 6 + React 18 + TypeScript 5 + Tailwind CSS 4 (`@tailwindcss/vite`), React Router 7.

- **SPA serving:** `/api/*` paths NEVER fall through to the SPA (unmatched `/api/*` = plain 404); `/assets/*` served with correct MIME + `Cache-Control: public, max-age=31536000, immutable` (Vite content-hashes filenames); every other path serves the SPA shell (`index.html`), with OG tags injected for `/p/{slug}` (HTML-escaped values — the injected title/description come from user-supplied project fields).
- **Placeholder shell:** `portal/dist/index.html` is COMMITTED (a minimal shell containing the literal marker `<!--OG-->` and `<div id="root"></div>`); everything else under `portal/dist/` is gitignored. /// Field caps for everything the PUBLIC portal page renders (slice-2 gate).
```rust
/// `None` = the caller is not setting that field. `chat_link` additionally must
/// look like a plain http(s) URL — the portal renders it as a clickable link,
/// so a `javascript:` scheme would be a stored-XSS vector.
pub(crate) fn validate_project_texts(
    description: Option<&str>,
    chat_link: Option<&str>,
    data_policy_text: Option<&str>,
    goals: Option<&serde_json::Value>,
) -> Result<(), ApiError> {
    if description.is_some_and(|s| s.chars().count() > 5000) {
        return Err(ApiError::bad_request("description must be at most 5000 characters"));
    }
    if data_policy_text.is_some_and(|s| s.chars().count() > 10000) {
        return Err(ApiError::bad_request("dataPolicyText must be at most 10000 characters"));
    }
    if let Some(link) = chat_link {
        let link = link.trim();
        if !link.is_empty() {
            let scheme_ok = link.starts_with("https://") || link.starts_with("http://");
            let chars_ok = !link.chars().any(|c| c.is_whitespace() || c.is_control());
            if !(scheme_ok && chars_ok && link.chars().count() <= 300) {
                return Err(ApiError::bad_request(
                    "chatLink must be an http(s) URL, at most 300 characters, without spaces",
                ));
            }
        }
    }
    if let Some(goals) = goals {
        let serialized = serde_json::to_string(goals)
            .map_err(|e| ApiError::Internal(anyhow::Error::new(e).context("serialize goals")))?;
        if serialized.len() > 4096 {
            return Err(ApiError::bad_request("goals must serialize to at most 4096 bytes"));
        }
    }
    Ok(())
}
```

```rust
/// Numeric sanity for the announcement aggregates the PUBLIC page sums (slice-2
/// gate): a single member must not be able to turn the project progress block
/// into `inf`/negative garbage or bloat storage.
fn validate_aggregate_stats(stats: &Value) -> Result<(), ApiError> {
    let serialized = serde_json::to_string(stats)
        .map_err(|e| ApiError::Internal(anyhow::Error::new(e).context("serialize aggregateStats")))?;
    if serialized.len() > 16384 {
        return Err(ApiError::bad_request("aggregateStats must serialize to at most 16384 bytes"));
    }
    if let Some(by_filter) = stats.get("integrationSecondsByFilter") {
        let map = by_filter
            .as_object()
            .ok_or_else(|| ApiError::bad_request("integrationSecondsByFilter must be an object"))?;
        if map.len() > 50 {
            return Err(ApiError::bad_request("integrationSecondsByFilter allows at most 50 filters"));
        }
        for (filter, seconds) in map {
            if filter.is_empty() || filter.chars().count() > 40 {
                return Err(ApiError::bad_request("filter names must be 1..=40 characters"));
            }
            let v = seconds
                .as_f64()
                .ok_or_else(|| ApiError::bad_request("integration seconds must be numbers"))?;
            if !v.is_finite() || !(0.0..=1e9).contains(&v) {
                return Err(ApiError::bad_request("integration seconds must be finite, 0..=1e9"));
            }
        }
    }
    Ok(())
}
```

```rust
fn cookie_token(set_cookie: &str) -> String {
    let (name_value, attrs) = set_cookie.split_once(';').expect("attrs present");
    let (name, value) = name_value.split_once('=').expect("name=value");
    assert_eq!(name, "athenaeum_portal_session");
    for required in ["HttpOnly", "Secure", "SameSite=Lax", "Path=/"] {
```

```rust
pub(crate) async fn authenticate_otp(
    state: &AppState,
    headers: &HeaderMap,
    raw_email: &str,
    code: &str,
) -> Result<(String, i64), ApiError> {
    let email = normalize_email(raw_email);
    let ip = client_ip(headers);

    if over_verify_limit(&state.db, &email, ip.as_deref()).await? {
        invalidate_live_codes(&state.db, &email).await?;
        return Err(ApiError::Status(StatusCode::UNAUTHORIZED));
    }

    let candidate = sqlx::query_as::<_, OtpCandidate>(
        "SELECT id, code_hash FROM otp_codes \
         WHERE email = $1 AND consumed = false AND expires_at > now() \
         ORDER BY expires_at DESC LIMIT 1",
    )
    .bind(&email)
    .fetch_optional(&state.db)
    .await?;

    let matched = match &candidate {
        Some(c) if security::verify_otp_code(code, &c.code_hash) => Some(c.id),
        _ => None,
    };

    let Some(code_id) = matched else {
        if candidate.is_none() {
            security::dummy_verify();
        }
        record_verify_failure(&state.db, &email, ip.as_deref()).await?;
        return Err(ApiError::Status(StatusCode::UNAUTHORIZED));
    };

    Ok((email, code_id))
}

/// Atomic single-use consume of a matched code inside the caller's transaction.
/// `false` = lost the concurrent race (caller must roll back and 401).
pub(crate) async fn consume_code_tx(
    conn: &mut sqlx::PgConnection,
    code_id: i64,
) -> Result<bool, ApiError> {
    let consumed: Option<(i64,)> = sqlx::query_as(
        "UPDATE otp_codes SET consumed = true WHERE id = $1 AND consumed = false RETURNING id",
    )
    .bind(code_id)
    .fetch_optional(conn)
    .await?;
    Ok(consumed.is_some())
}

/// email == account; first successful verify creates it.
pub(crate) async fn upsert_account_tx(
    conn: &mut sqlx::PgConnection,
    email: &str,
) -> Result<Uuid, ApiError> {
    let account_id: Uuid = sqlx::query_scalar(
        "INSERT INTO accounts (email) VALUES ($1) \
         ON CONFLICT (email) DO UPDATE SET email = EXCLUDED.email RETURNING id",
    )
    .bind(email)
    .fetch_one(conn)
    .await?;
    Ok(account_id)
}
```

```rust
//! Portal (browser) session sign-in — the SAME email-OTP flow as device
//! verify, but the redemption creates a `portal_sessions` row + an HttpOnly
//! cookie instead of a device. Sessions are account identities WITHOUT a
//! device: never a snapshot member node, never a package holder.

use axum::extract::State;
use axum::http::{header, HeaderMap, StatusCode};
use axum::response::IntoResponse;
use axum::Json;
use serde::Deserialize;

use crate::error::ApiError;
use crate::routes::{auth, AppState};
use crate::security;

/// Session cookie name. HttpOnly + Secure + SameSite=Lax + Path=/.
pub const SESSION_COOKIE: &str = "athenaeum_portal_session";
/// Session lifetime.
pub(crate) const SESSION_TTL_DAYS: i32 = 30;

/// Extract the session token from a `Cookie` header (manual parse — one tiny
/// well-understood format beats a dependency).
pub(crate) fn session_cookie_value(headers: &HeaderMap) -> Option<String> {
    let raw = headers.get(header::COOKIE)?.to_str().ok()?;
    raw.split(';').find_map(|pair| {
        let (name, value) = pair.trim().split_once('=')?;
        (name == SESSION_COOKIE && !value.is_empty()).then(|| value.to_string())
    })
}

#[derive(Deserialize)]
#[serde(rename_all = "camelCase")]
pub struct PortalVerifyRequest {
    email: String,
    code: String,
}

/// Redeem an OTP into a portal session. 204 + Set-Cookie on success; the same
/// uniform 401 as device verify on any wrong/expired/consumed code (shared
/// lockout budgets by construction — `auth::authenticate_otp`).
#[tracing::instrument(skip_all)]
pub async fn portal_verify(
    State(state): State<AppState>,
    headers: HeaderMap,
    Json(body): Json<PortalVerifyRequest>,
) -> Result<impl IntoResponse, ApiError> {
    let (email, code_id) = auth::authenticate_otp(&state, &headers, &body.email, &body.code).await?;

    let mut tx = state.db.begin().await?;
    if !auth::consume_code_tx(&mut tx, code_id).await? {
        tx.rollback().await?;
        return Err(ApiError::Status(StatusCode::UNAUTHORIZED));
    }
    let account_id = auth::upsert_account_tx(&mut tx, &email).await?;

    let token = security::generate_device_token();
    sqlx::query(
        "INSERT INTO portal_sessions (account_id, token_hash, expires_at) \
         VALUES ($1, $2, now() + make_interval(days => $3))",
    )
    .bind(account_id)
    .bind(security::hash_token(&token))
    .bind(SESSION_TTL_DAYS)
    .execute(&mut *tx)
    .await?;
    tx.commit().await?;

    tracing::info!(account_id = %account_id, "portal session created");
    let cookie = format!(
        "{SESSION_COOKIE}={token}; Path=/; HttpOnly; Secure; SameSite=Lax; Max-Age={}",
        (SESSION_TTL_DAYS as i64) * 86_400
    );
    Ok((StatusCode::NO_CONTENT, [(header::SET_COOKIE, cookie)]))
}

/// Kill the calling session (idempotent) and expire the cookie. No CSRF header
/// needed: SameSite=Lax already blocks cross-site POSTs, and a forced logout is
/// a nuisance, not a privilege.
#[tracing::instrument(skip_all)]
pub async fn portal_logout(
    State(state): State<AppState>,
    headers: HeaderMap,
) -> Result<impl IntoResponse, ApiError> {
    if let Some(token) = session_cookie_value(&headers) {
        sqlx::query("DELETE FROM portal_sessions WHERE token_hash = $1")
            .bind(security::hash_token(&token))
            .execute(&state.db)
            .await?;
    }
    let clear = format!("{SESSION_COOKIE}=; Path=/; HttpOnly; Secure; SameSite=Lax; Max-Age=0");
    Ok((StatusCode::NO_CONTENT, [(header::SET_COOKIE, clear)]))
}
```

```rust
/// Account identity for collab endpoints: EITHER a device bearer token
/// (`device_id: Some`) OR a portal session cookie (`device_id: None`). Collab
/// handlers only need `account_id`; the few device-granular actions
/// (have-reports) demand `device_id` themselves.
#[derive(Debug, Clone)]
pub struct AuthAccount {
    pub account_id: Uuid,
    pub device_id: Option<Uuid>,
}

/// Bearer-or-session authentication for collab routes.
///
/// Order matters: an EXPLICIT bearer token is authoritative — if it is invalid
/// the request is 401 even when a valid cookie is also present (a client that
/// sends a token expects token semantics; silently downgrading to a session
/// would mask token revocation). Cookie-authenticated mutations (non-GET/HEAD)
/// must carry `x-portal-csrf: 1` — the SPA sets it on every write; a cross-site
/// form cannot (custom headers require a same-origin caller or a CORS
/// preflight, which this API never grants). SameSite=Lax is the first line,
/// this header is the belt-and-braces.
pub async fn require_account(
    State(state): State<AppState>,
    mut req: Request,
    next: Next,
) -> Result<Response, ApiError> {
    if let Some(token) = bearer_token(req.headers()) {
        let token_hash = security::hash_token(&token);
        let row = sqlx::query_as::<_, AuthRow>(
            "SELECT id, account_id, role FROM devices \
             WHERE token_hash = $1 AND revoked_at IS NULL",
        )
        .bind(&token_hash)
        .fetch_optional(&state.db)
        .await?;
        let Some(device) = row else {
            return Err(ApiError::Status(StatusCode::UNAUTHORIZED));
        };
        stamp_device_last_seen(&state, device.id).await;
        req.extensions_mut().insert(AuthAccount {
            account_id: device.account_id,
            device_id: Some(device.id),
        });
        return Ok(next.run(req).await);
    }

    let Some(session_token) = crate::routes::portal_auth::session_cookie_value(req.headers()) else {
        return Err(ApiError::Status(StatusCode::UNAUTHORIZED));
    };
    let row: Option<(Uuid, Uuid)> = sqlx::query_as(
        "SELECT id, account_id FROM portal_sessions \
         WHERE token_hash = $1 AND expires_at > now()",
    )
    .bind(security::hash_token(&session_token))
    .fetch_optional(&state.db)
    .await?;
    let Some((session_id, account_id)) = row else {
        return Err(ApiError::Status(StatusCode::UNAUTHORIZED));
    };

    let method = req.method();
    if method != axum::http::Method::GET
        && method != axum::http::Method::HEAD
        && req.headers().get("x-portal-csrf").is_none()
    {
        return Err(ApiError::Status(StatusCode::FORBIDDEN));
    }

    // Throttled liveness stamp, mirroring devices — non-fatal, never swallowed.
    if let Err(err) = sqlx::query(
        "UPDATE portal_sessions SET last_seen_at = now() \
         WHERE id = $1 \
           AND (last_seen_at IS NULL OR last_seen_at < now() - interval '1 minute')",
    )
    .bind(session_id)
    .execute(&state.db)
    .await
    {
        tracing::warn!(session_id = %session_id, error = %err, "session last_seen_at update failed");
    }

    req.extensions_mut().insert(AuthAccount {
        account_id,
        device_id: None,
    });
    Ok(next.run(req).await)
}

/// Shared throttled `devices.last_seen_at` stamp (used by both middlewares).
async fn stamp_device_last_seen(state: &AppState, device_id: Uuid) {

         WHERE id = $1 \
           AND (last_seen_at IS NULL OR last_seen_at < now() - interval '1 minute')",
    )
    .bind(device_id)
    .execute(&state.db)
    .await
    {
        tracing::warn!(device_id = %device_id, error = %err, "last_seen_at update failed");
    }
}
```

```rust
pub async fn my_projects(
    State(state): State<AppState>,
    Extension(auth): Extension<AuthAccount>,
) -> Result<Json<Vec<MyProjectView>>, ApiError> {
    let rows = sqlx::query_as::<_, MyProjectRow>(
        "SELECT p.id, p.slug, p.title, pm.data_role, pm.is_coordinator, p.require_approval, \
                (SELECT count(*) FROM package_announcements a \
                 WHERE a.project_id = p.id AND a.state = 'pending' AND pm.is_coordinator) \
                    AS pending_announcements \
         FROM project_members pm \
         JOIN projects p ON p.id = pm.project_id \
         WHERE pm.account_id = $1 \
         ORDER BY p.created_at DESC",
    )
    .bind(auth.account_id)
    .fetch_all(&state.db)
    .await?;

        rows.into_iter()

                slug: r.slug,
                title: r.title,
                data_role: r.data_role,
                coordinator: r.is_coordinator,
                require_approval: r.require_approval,
```

```ts
/** Typed fetch wrapper for the hub API. Mutations carry the CSRF header the
 * hub's session middleware demands; cookies ride same-origin automatically. */
export class ApiError extends Error {
  status: number;
  constructor(status: number, message: string) {
    super(message);
    this.status = status;
  }
}

async function request<T>(method: string, url: string, body?: unknown): Promise<T> {
  const headers: Record<string, string> = {};
  if (method !== 'GET') headers['x-portal-csrf'] = '1';
  if (body !== undefined) headers['content-type'] = 'application/json';
  const resp = await fetch(url, {
    method,
    headers,
    credentials: 'same-origin',
    body: body === undefined ? undefined : JSON.stringify(body),
  });
  if (!resp.ok) {
    let message = `${resp.status}`;
    try {
      const data = await resp.json();
      if (data && typeof data.error === 'string') message = data.error;
    } catch {
      /* body-less error — keep the status string */
    }
    throw new ApiError(resp.status, message);
  }
  if (resp.status === 204) return undefined as T;
  return (await resp.json()) as T;
}

export const apiGet = <T>(url: string) => request<T>('GET', url);
export const apiPost = <T>(url: string, body?: unknown) => request<T>('POST', url, body);
export const apiPatch = <T>(url: string, body?: unknown) => request<T>('PATCH', url, body);
export const apiDelete = <T>(url: string) => request<T>('DELETE', url);
```

```ts
/** Session state: `me` is null while signed out, `loading` only on first load. */
export function useMe() {
  const [me, setMe] = useState<Me | null>(null);
  const [loading, setLoading] = useState(true);

  const refresh = useCallback(async () => {
    try {
      setMe(await apiGet<Me>('/api/v1/me'));
    } catch (err) {
      if (err instanceof ApiError && err.status === 401) setMe(null);
      else console.error('[portal] me failed:', err);
    } finally {
      setLoading(false);
    }
  }, []);

  useEffect(() => {
    void refresh();
  }, [refresh]);

  return { me, loading, refresh };
}
```

```rust
// src/portal_serve.rs
//! Serve the portal SPA from the binary. Vite content-hashes /assets/* so
//! those are immutable-cacheable; every other non-/api path gets the shell
//! (client-side routing), with OpenGraph tags injected for /p/{slug} so a
//! project link unfurls in Discord (spec §6). rust-embed reads portal/dist
//! from disk in debug builds and embeds it in release builds.

use axum::extract::State;
use axum::http::{header, StatusCode, Uri};
use axum::response::{Html, IntoResponse, Response};
use rust_embed::RustEmbed;

use crate::routes::projects::resolve_project;
use crate::routes::AppState;

#[derive(RustEmbed)]
#[folder = "portal/dist/"]
struct PortalAssets;

/// Minimal HTML escape for OG attribute values (user-supplied project fields).
fn html_escape(s: &str) -> String {
    s.replace('&', "&amp;")
        .replace('<', "&lt;")
        .replace('>', "&gt;")
        .replace('"', "&quot;")
        .replace('\'', "&#39;")
}

/// Router fallback: assets, then the shell (with OG for /p/{slug}).
pub async fn spa_fallback(State(state): State<AppState>, uri: Uri) -> Response {
    let path = uri.path();

    // The API namespace never falls through to HTML — an unknown API path is
    // an honest 404, not a 200 shell that confuses clients.
    if path.starts_with("/api/") {
        return StatusCode::NOT_FOUND.into_response();
    }

    // Static assets (content-hashed by Vite → safe to cache forever).
    let trimmed = path.trim_start_matches('/');
    if !trimmed.is_empty() && trimmed != "index.html" {
        if let Some(file) = PortalAssets::get(trimmed) {
            let mime = mime_guess::from_path(trimmed).first_or_octet_stream();
            let cache = if trimmed.starts_with("assets/") {
                "public, max-age=31536000, immutable"
            } else {
                "no-cache"
            };
            return (
                [
                    (header::CONTENT_TYPE, mime.as_ref().to_string()),
                    (header::CACHE_CONTROL, cache.to_string()),
                ],
                file.data,
            )
                .into_response();
        }
    }

    // The SPA shell. Missing dist (fresh checkout without the placeholder)
    // is a served-as-500 configuration error, honestly reported.
    let Some(shell) = PortalAssets::get("index.html") else {
        tracing::error!("portal/dist/index.html missing — SPA not built and placeholder absent");
        return StatusCode::INTERNAL_SERVER_ERROR.into_response();
    };
    let mut html = String::from_utf8_lossy(&shell.data).into_owned();

    // OG injection for project pages: /p/{slug} (first segment only).
    if let Some(rest) = path.strip_prefix("/p/") {
        let slug = rest.split('/').next().unwrap_or("");
        if !slug.is_empty() {
            if let Ok(project) = resolve_project(&state.db, slug).await {
                let title = html_escape(&project.title);
                let description = html_escape(&format!(
                    "{} — RA {:.2}°, Dec {:.2}°, r {:.1}°. A collaborative imaging project on Athenaeum.",
                    project.target_name,
                    project.target_ra_deg,
                    project.target_dec_deg,
                    project.target_radius_deg
                ));
                let tags = format!(
                    "<meta property=\"og:title\" content=\"{title}\" />\n\
                     <meta property=\"og:description\" content=\"{description}\" />\n\
                     <meta property=\"og:type\" content=\"website\" />\n\
                     <meta property=\"og:site_name\" content=\"Athenaeum Projects\" />"
                );
                html = html.replace("<!--OG-->", &tags);
            }
        }
    }

    ([(header::CACHE_CONTROL, "no-cache".to_string())], Html(html)).into_response()
}
```

```tsx
  const [code, setCode] = useState('');

      setBusy(false);

      setError(err instanceof ApiError && err.status === 401 ? 'Wrong or expired code.' : 'Sign-in failed.');
      setBusy(false);
    }
  };

      <h1 className="text-xl font-semibold">Sign in</h1>
      {stage === 'email' ? (
```

```tsx
// portal/src/pages/Admin.tsx
import { FormEvent, useCallback, useEffect, useState } from 'react';
import { Link, useParams } from 'react-router-dom';
import { apiGet, apiPatch, apiPost, ApiError } from '../api';
import { useMe } from '../useMe';
import { JoinRequestView, MyProject, ProjectPageData, ThresholdView } from '../types';

/** Metric keys whose cross-setup comparison is dishonest (spec §4) — the
 * editor shows a warning when a rule uses one. */
const ADVANCED_METRICS = new Set(['median_snr', 'snr_weight', 'frame_snr']);

interface Rule {
  metricKey: string;
  op: string;
  value: number | boolean;
}

export default function Admin() {
  const { slug } = useParams();
  const { me, loading } = useMe();
  const [page, setPage] = useState<ProjectPageData | null>(null);
  const [membership, setMembership] = useState<MyProject | null>(null);
  const [requests, setRequests] = useState<JoinRequestView[]>([]);
  const [rules, setRules] = useState<Rule[]>([]);
  const [thresholdVersion, setThresholdVersion] = useState<number | null>(null);
  const [status, setStatus] = useState<string | null>(null);

  const projectId = page?.project.id;

  const reload = useCallback(async () => {
    const p = await apiGet<ProjectPageData>(`/api/v1/projects/${slug}`);
    setPage(p);
    const mine = await apiGet<MyProject[]>('/api/v1/me/projects');
    const m = mine.find((x) => x.id === p.project.id) ?? null;
    setMembership(m);
    if (m?.coordinator) {
      setRequests(await apiGet<JoinRequestView[]>(`/api/v1/projects/${p.project.id}/join-requests`));
      const t = await apiGet<{ current: ThresholdView | null }>(`/api/v1/projects/${p.project.id}/thresholds`);
      setRules(t.current?.rules ?? []);
      setThresholdVersion(t.current?.version ?? null);
    }
  }, [slug]);

  useEffect(() => {
    if (!loading && me) reload().catch((err) => console.error('[portal] admin load failed:', err));
  }, [loading, me, reload]);

  if (loading) return <p className="text-neutral-500">Loading…</p>;
  if (!me)
    return (
      <p className="text-sm">
        <Link to="/signin" className="underline">
          Sign in
        </Link>{' '}
        first.
      </p>
    );
  if (!page) return <p className="text-neutral-500">Loading…</p>;
  if (!membership?.coordinator)
    return (
      <p className="text-sm text-neutral-500">
        Only the coordinator can administer this project. <Link to={`/p/${slug}`} className="underline">Back to the project.</Link>
      </p>
    );

  const act = async (fn: () => Promise<unknown>, okMessage: string) => {
    setStatus(null);
    try {
      await fn();
      await reload();
      setStatus(okMessage);
    } catch (err) {
      setStatus(err instanceof ApiError ? `Error: ${err.message}` : 'Error.');
    }
  };

  return (
    <div className="space-y-8">
      <h1 className="text-xl font-semibold">Admin — {page.project.title}</h1>
      {status && <p className="text-sm text-neutral-500">{status}</p>}

      {membership.pendingAnnouncements > 0 && (
        <div className="rounded border border-amber-500/40 bg-amber-500/10 px-4 py-3 text-sm">
          {membership.pendingAnnouncements} contribution{membership.pendingAnnouncements === 1 ? '' : 's'} awaiting your approval — review the
          frames in the Athenaeum app (Projects → {page.project.title} → Moderation).
        </div>
      )}

      <section className="space-y-2">
        <h2 className="font-semibold">Join requests</h2>
        {requests.length === 0 && <p className="text-sm text-neutral-500">None open.</p>}
        {requests.map((r) => (
          <JoinRow key={r.id} request={r} projectId={projectId!} onDone={() => void reload()} />
        ))}
      </section>

      <ThresholdEditor
        rules={rules}
        version={thresholdVersion}
        onSave={(next) => void act(() => apiPost(`/api/v1/projects/${projectId}/thresholds`, { rules: next }), 'Thresholds saved.')}
      />

      <SettingsEditor page={page} onPatch={(body, ok) => void act(() => apiPatch(`/api/v1/projects/${projectId}`, body), ok)} />
    </div>
  );
}

function JoinRow({ request, projectId, onDone }: { request: JoinRequestView; projectId: string; onDone: () => void }) {
  const [role, setRole] = useState<string>(request.desiredRole);
  const decide = async (verb: 'approve' | 'reject') => {
    try {
      await apiPost(
        `/api/v1/projects/${projectId}/join-requests/${request.id}/${verb}`,
        verb === 'approve' ? { dataRole: role } : {},
      );
    } catch (err) {
      console.error('[portal] decide failed:', err);
    }
    onDone();
  };
  return (
    <div className="flex flex-wrap items-center gap-2 rounded border border-neutral-200 px-3 py-2 text-sm dark:border-neutral-800">
      <span className="font-medium">{request.displayName}</span>
      <span className="text-neutral-500">wants {request.desiredRole}</span>
      {request.message && <span className="text-neutral-500">— “{request.message}”</span>}
      <div className="ml-auto flex items-center gap-2">
        <select value={role} onChange={(e) => setRole(e.target.value)} className="rounded border border-neutral-300 bg-transparent px-2 py-1 dark:border-neutral-700">
          <option value="send">send</option>
          <option value="send_receive">send & receive</option>
        </select>
        <button onClick={() => void decide('approve')} className="rounded bg-neutral-900 px-3 py-1 text-white dark:bg-neutral-100 dark:text-neutral-900">
          Approve
        </button>
        <button onClick={() => void decide('reject')} className="underline">
          Reject
        </button>
      </div>
    </div>
  );
}

function ThresholdEditor({ rules, version, onSave }: { rules: Rule[]; version: number | null; onSave: (rules: Rule[]) => void }) {
  const [draft, setDraft] = useState<Rule[]>(rules);
  useEffect(() => setDraft(rules), [rules]);
  const hasAdvanced = draft.some((r) => ADVANCED_METRICS.has(r.metricKey));

  const update = (i: number, patch: Partial<Rule>) => setDraft(draft.map((r, j) => (j === i ? { ...r, ...patch } : r)));
  const field = 'rounded border border-neutral-300 bg-transparent px-2 py-1 text-sm dark:border-neutral-700';

  return (
    <section className="space-y-2">
      <h2 className="font-semibold">Quality thresholds {version != null && <span className="text-sm font-normal text-neutral-500">(v{version})</span>}</h2>
      {draft.map((r, i) => (
        <div key={i} className="flex items-center gap-2">
          <input value={r.metricKey} onChange={(e) => update(i, { metricKey: e.target.value })} className={`${field} w-44`} />
          <input value={r.op} onChange={(e) => update(i, { op: e.target.value })} className={`${field} w-24`} />
          <input
            value={String(r.value)}
            onChange={(e) => {
              const raw = e.target.value;
              const asNumber = Number(raw);
              update(i, { value: raw === 'true' ? true : raw === 'false' ? false : Number.isNaN(asNumber) ? 0 : asNumber });
            }}
            className={`${field} w-24`}
          />
          <button onClick={() => setDraft(draft.filter((_, j) => j !== i))} className="text-sm text-neutral-500 underline">
            remove
          </button>
        </div>
      ))}
      <div className="flex gap-3">
        <button onClick={() => setDraft([...draft, { metricKey: 'fwhm_arcsec', op: 'lte', value: 3.5 }])} className="text-sm underline">
          Add rule
        </button>
        <button onClick={() => onSave(draft)} disabled={draft.length === 0} className="rounded bg-neutral-900 px-3 py-1 text-sm text-white disabled:opacity-50 dark:bg-neutral-100 dark:text-neutral-900">
          Save as new version
        </button>
      </div>
      {hasAdvanced && (
        <p className="text-xs text-amber-600">
          SNR-family metrics depend on exposure and gear — values are not comparable across members’ setups. Prefer FWHM/eccentricity/star
          counts.
        </p>
      )}
      <p className="text-xs text-neutral-500">Changes are prospective: already-published frames stay published.</p>
    </section>
  );
}

function SettingsEditor({ page, onPatch }: { page: ProjectPageData; onPatch: (body: Record<string, unknown>, ok: string) => void }) {
  const p = page.project;
  const [description, setDescription] = useState(p.description);
  const [chatLink, setChatLink] = useState(p.chatLink ?? '');
  const [dataPolicyText, setDataPolicyText] = useState(p.dataPolicyText);
  const field = 'w-full rounded border border-neutral-300 bg-transparent px-3 py-1.5 text-sm dark:border-neutral-700';

  const save = (e: FormEvent) => {
    e.preventDefault();
    onPatch({ description, chatLink: chatLink.trim() || undefined, dataPolicyText }, 'Settings saved.');
  };

  return (
    <section className="max-w-lg space-y-3">
      <h2 className="font-semibold">Settings</h2>
      <form onSubmit={save} className="space-y-2">
        <textarea maxLength={5000} rows={4} value={description} onChange={(e) => setDescription(e.target.value)} className={field} />
        <input maxLength={300} value={chatLink} onChange={(e) => setChatLink(e.target.value)} placeholder="Chat link (https://…)" className={field} />
        <textarea maxLength={10000} rows={3} value={dataPolicyText} onChange={(e) => setDataPolicyText(e.target.value)} className={field} />
        <button className="rounded bg-neutral-900 px-3 py-1.5 text-sm text-white dark:bg-neutral-100 dark:text-neutral-900">Save settings</button>
      </form>
      <div className="flex gap-3 text-sm">
        <button
          onClick={() => onPatch({ requireApproval: !p.requireApproval }, p.requireApproval ? 'Manual approval disabled.' : 'Manual approval enabled.')}
          className="underline"
        >
          {p.requireApproval ? 'Disable' : 'Enable'} manual contribution approval
        </button>
        <button
          onClick={() => onPatch({ status: p.status === 'active' ? 'closed' : 'active' }, p.status === 'active' ? 'Project closed.' : 'Project reopened.')}
          className="underline"
        >
          {p.status === 'active' ? 'Close to new members' : 'Reopen'}
        </button>
      </div>
    </section>
  );
}
```
