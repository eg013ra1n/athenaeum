Design notes (hide with the toggle above)
  • One hierarchy, top to bottom. Title (13 px semibold) → one stats row in the Duplicates-toolbar style (12 px; number in text-content or a status colour, label muted, · in text-border) → service facts as 11 px Chips → one explanatory sentence, 11 px faint → the list → footer. Counts are never the same size as sentences any more.
  • Grammar is built from counts in the UI (1 frame / 2 frames, "is / are"), not copied from the backend sentence. No API names (onlyUnsolved) in the window.
  • Say it once. What all frames of a folder share (object, filter, exposure, position hint, "no plate solve stored", why a value is proposed) sits on the group row. A frame row repeats only what differs from its group: a position hint, its own evidence, a lock reason as a chip (full text on hover). A reason that holds for the whole group (metadata "No value found") is on the group row, not on 1 829 rows.
  • Dense table = Missing Metadata: sticky header bg-surface-hover text-xs font-semibold text-content-secondary, group row bg-accent/15 with the folder (mono, as there), one-line rows py-1, file names 12 px in the UI font (the Missing Metadata page uses 14 px mono; here names must stay below the 13 px title). Per group ~12 rows, then "+N more" (expands in place). Black Hole keeps its Duplicates groups unchanged.
  • Pinned parts. Stats, facts and footer do not scroll; the sticky table header and the list do. In code the summary block becomes shrink-0 above the scrolling body (a small DialogShell child-layout change) or a sticky block with the measured offset the Missing Metadata table already uses.
  • Confirmation of an action over N frames = SetFrameTypeModal: the footer reads N of M (ticked of offered), then Cancel / Apply. A group pill says "Solve 118 of 118" the way Duplicates says "Delete 2 of 3". Sizes appear only where the plan has them (Black Hole); a plate solve never shows "0 B".
  • Where each backend note goes (the backend still sends notes: string[]; this needs it structured, see open question 1):

  • Light theme. The app has no light overrides in src/ (only color-scheme: light dark); the light set here is a Snow Storm mapping so the owner can judge contrast. Dark uses the exact tokens.
